## 현재 CI 범위와 별도 검토 항목

현재 방침은 **프런트엔드만 CI에서 검사**하는 것이다. 백엔드 CI는 필수 미완료 작업으로
취급하지 않는다. 다음 항목은 필요성과 운영 비용을 검토한 뒤 범위를 별도로 결정한다.

- 비밀정보 검사 자동화와 의존성·이미지 취약점 검사 및 업데이트 알림.
- 프런트엔드 Docker 이미지 빌드·발행.
- 백엔드 테스트·race 검사·PostgreSQL 통합 테스트·컨테이너 빌드의 CI 편입.

현재 파이프라인에는 위 단계가 없다. 백엔드의 로컬 테스트·빌드 결과는 원격 CI와 구분해서 기록한다.

접근성·공개 점검을 먼저 수행하고, 배포 방식·운영 주소·이미지 발행은 후속 결정으로 둔다.
아래 항목은 실행 절차이며 완료 증거가 없는 항목을 통과로 표시하지 않는다.

### 접근성 검증

현재 소스와 격리된 builtin 런타임, 합성 익명 세션을 사용한다. 실제 HTTP 접속과
연결 준비 완료를 먼저 확인한다. 이전 로컬 서버는 ready 로그 이후에도 HTTP timeout이
발생했으므로 서버 로그만으로 브라우저 검증 준비 완료를 판단하지 않는다.
기존 로컬 fixture는 모의 API를 사용하며 실환경 검증 완료 증거로 대체하지 않는다.

| 항목 | 절차 및 합격 기준 | 상태 |
| --- | --- | --- |
| Windows 한글 IME | 조합 중 Enter로 전송되지 않음, 조합 완료 후 Enter 1회 전송, Shift+Enter 줄바꿈, 실패 후 새 초안 유지 | 미실행 |
| 브라우저 확대 | Chrome/Firefox 실제 줌 200%·400%에서 대화·메뉴·작업·입력 접근, 내용 잘림·가로 넘침·포커스 가림 확인; 글자 크기 변경이나 viewport 축소로 대체하지 않음 | 미실행 |
| Windows 고대비 | 실제 고대비 테마에서 진행률 0/42/100%, 상태 텍스트, 컨트롤 경계와 포커스 확인; 종료 후 원래 설정 복원 | 미실행 |
| Firefox | 일반/강제 색상에서 진행률 트랙·채움, 이름·값 및 입력 동작 확인 | 미실행 |
| 스크린리더 | 사용 도구/버전을 기록하고 입력 label·도움말·별칭 오류/성공·전송 실패·작업 상태/진행률 낭독과 Tab 이동 확인 | 미실행 |

확인한 실행 파일: Firefox 기본 설치 경로 존재. NVDA 기본 설치 경로는 없으며,
다른 경로 설치 여부나 실행 가능 여부까지 판정한 것은 아니다. 사용 가능한 스크린리더를
선정한 뒤 검사한다. OS 설정 변경이 필요한 검사는 설정 변경 범위와 복원 방법을 먼저 정한다.
각 결과에는 커밋, OS/브라우저/보조기기 버전, 실제 조작 순서, 기대·실제 결과와 증거를 남긴다.

### 공개 점검

1. 원격 브랜치·태그 목록을 확정하고 검사할 이력 범위를 기록한다. 로컬 전용 snapshot ref를
   공개 대상으로 포함하거나 `--mirror`로 업로드하지 않는다.
2. 비밀정보 스캐너로 대상 이력과 현재 추적 파일을 검사한다. 보고서는 값을 마스킹하며
   실제 자격 증명이 발견되면 공개 문서에 원문을 넣지 않는다. Windows PATH에서 gitleaks는
   발견되지 않았으므로 WSL/기존 설치 확인 또는 검사 도구 준비가 필요하다.
3. 이름·커밋 작성자 이메일·서비스/내부 주소 및 공개 이슈·PR·릴리스·아티팩트를 확인한다.
   이력 재작성이나 공개 범위 변경은 점검 결과와 분리한다.
4. 추적 파일과 루트/프런트엔드 Docker 빌드 컨텍스트를 각각 검사한다. 이번 파일명 검사에서
   `.env`, 개인키·인증서·덤프 확장자는 없었고 `.sql`은 마이그레이션 4개였다.
   이는 내용 검사 또는 실제 빌드 컨텍스트 검사 통과를 의미하지 않는다.
5. 코드·자산 출처와 사용 조건을 확인하고 CI 자격 증명의 권한을 검토한다.

운영 비밀값 분리·TLS/Origin·DB 백업과 복원·실제 모델 연동·배포/롤백 검증은
운영 배포 대상이 결정된 뒤 구체화한다. 개발용 Compose와 전용 LXC 구성을 운영 완료로 간주하지 않는다.
